# Demo assets

Screenshots for the slides and the README (PNG, keep each under ~1 MB). Name them by scene, e.g.
`1-dagshub-models.png`, `4-grafana-storm.png`.

Videos are **not** stored here: git ignores video files (see the repository `.gitignore`). Upload the video to
YouTube (unlisted) or Google Drive and link it from [../video.md](../video.md).

Never commit a screenshot that shows secrets (`.env`, tokens) or rows of the competition data.
